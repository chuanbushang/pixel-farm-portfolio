Hey there, thanks for the download!

Since you're reading this, I assume you want to know how to apply the compatibility patches. It's pretty easy:
First, find the folder containing the image files for the mod whose images you want to replace. Copy the files, then simply paste them in the actual mod folder's assets folder, ideally after making a backup of the original files. When you're asked if you want to replace the files, say yes. Done!

If you want to use this interface with something like Seasonal Vanilla UI (https://www.nexusmods.com/stardewvalley/mods/17272), that's totally possible! All you need to do is add this mod's (VPR-Inspired UI) ID to the other mod's manifest.json as a so-called false dependency. Don't worry, it's way easier than it sounds. For information about the process, please see https://stardewmodding.wiki.gg/wiki/Tutorial:_How_to_Add_a_False_Dependency_for_Load_Orders

If you've got any questions or feedback, please leave a comment and I'll get back to you as soon as possible. :)
